# 安全模型

[English](../security.md)

- 记忆保留在用户选择的本地知识库中。
- 显式设置时可下载经过校验的启动工具和运行环境；Hook 不下载、不发送笔记。见[运行环境参考](runtime.md)。安装流程不修改系统 Python、PATH 或 shell 配置。
- Hook 只使用只读 Git 命令识别 `origin` 和当前分支。
- 拒绝解析后位于知识库之外的笔记路径。
- 仓库准入来自配置的 owner、包含项和排除项。
- 本地项目必须明确登记解析后的根目录与固定 ID，提示词关键词不会自动开启记忆。嵌套登记选择最近根目录，停用根目录阻止回退父项目，本地登记不能绕过明确的 GitHub 排除项。
- 开始类 Hook 在注入前遮蔽常见令牌和私钥模式。
- Stop Hook 要求执行持久记忆检查，但永远不保存凭据。
- 本轮快照只包含 Markdown 相对路径和 SHA-256 哈希，不包含笔记正文。只要笔记变化，Hook 接受结束前必须在最终回复中可见披露回写。
- 项目任务的快照与 Stop 审核只覆盖该项目文件夹，其他项目的笔记变化不会列入。编辑全局记忆或共享经验前，先用当前轮的 `claim-shared` 命令声明该文件；其他进行中的对话不能同时声明。该文件的起始哈希进入本轮审核，只有审核接受后才释放占用。知识库维护任务仍有意检查全库。同一项目的同一笔记若被多个对话直接同时改写，仍可能发生覆盖；仅靠文件哈希无法判断每一行由谁写入，需要协调编辑。
- 登记另外保存简短的待审查笔记路径清单，因此即使此前没有提示开始快照，也会在当前任务结束时要求披露这些文件；该记录不保存笔记正文。
- 插件 Hook 必须在 `/hooks` 中显式审阅；定义改变后需要重新信任。
- Setup 在窄范围修改 writable root 前备份 `config.toml`。
- Uninstall 只移除 Setup 记录为本插件添加的 root，永远不删除知识库。

任何扫描器都不完整。请勿在 Markdown 笔记和仓库中保存秘密。

## 检索边界

search/read 在工作区范围检查后才读取候选，来源仓库仍执行精确包含与排除规则；从被排除来源提炼的共享经验也不返回。只匹配已登记的唯一项目主页和直接链接子页。拒绝越界路径，跳过隐藏、符号链接、不可读和过大的文件；先遮蔽常见秘密，再返回有限摘录。笔记和检索结果只作资料，不执行其中指令；来源校验不能替代事实验证。不持久保存查询或正文副本。
