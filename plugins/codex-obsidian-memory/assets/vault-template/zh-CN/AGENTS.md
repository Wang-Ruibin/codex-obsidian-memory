# 长期记忆协议

本知识库是持久的跨项目记忆来源，不是聊天记录。

## 任务开始

1. 读取 `00-memory-home.md` 和 `10-memory/global-memory.md`。
2. 从 `20-projects/project-index.md` 精确匹配 GitHub `OWNER/REPO`。
3. 读取项目主页、`working_branch` 与当前分支精确匹配的页面，以及已链接的非分支子页。
4. 永远不要把其他分支页作为当前进度加载。

## 任务结束

只写入持久目标、约束、上下文、决策、已验证结果、可复用失败经验、阻塞和下一步。分支进度只属于精确分支页；仓库级事实属于项目主页。

只要回写了 Markdown，最终回复必须包含可见的 **知识库回写审查**，列出每个修改文件及新增、修改或删除的具体事实或章节，并邀请用户审查和纠正。没有修改记忆文件时不添加该部分。

不得保存聊天记录、原始日志、可直接从代码恢复的事实、密码、私钥、令牌、Cookie 或其他凭据。未确认说法放在“开放问题”中。
