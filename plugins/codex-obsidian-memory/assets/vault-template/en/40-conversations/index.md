# Conversation memory

← [[00-memory-home|Memory home]]

Ordinary conversations have memory off by default. Explicitly enable each
conversation you want to remember. Existing local project registrations remain
project memories. Keep durable facts in the matching conversation note, without
copying transcripts or secrets. Turning memory off retains its note.
