# Long-term memory protocol / 长期记忆协议

## English

This vault is a durable cross-project memory source, not a chat transcript.

## Start of a task

1. Read `00-memory-home.md` and `10-memory/global-memory.md`.
2. Match the exact GitHub `OWNER/REPO` from `20-projects/project-index.md`.
3. Read the project home, the page whose `working_branch` exactly matches the current branch, and linked non-branch child pages.
4. Never load another branch page as current progress.

## End of a task

Write only durable goals, constraints, context, decisions, verified results, reusable failure lessons, blockers, and next steps. Branch progress belongs only on the exact branch page. Repository-wide facts belong on the project home.

Do not store chat transcripts, raw logs, facts directly recoverable from code, passwords, private keys, tokens, cookies, or other credentials. Put uncertain claims under Open questions.

## 中文

本知识库是持久的跨项目记忆来源，不是聊天记录。

### 任务开始

1. 读取 `00-memory-home.md` 和 `10-memory/global-memory.md`。
2. 从 `20-projects/project-index.md` 精确匹配 GitHub `OWNER/REPO`。
3. 读取项目主页、`working_branch` 与当前分支精确匹配的页面，以及已链接的非分支子页。
4. 永远不要把其他分支页作为当前进度加载。

### 任务结束

只写入持久目标、约束、上下文、决策、已验证结果、可复用失败经验、阻塞和下一步。分支进度只属于精确分支页；仓库级事实属于项目主页。

不得保存聊天记录、原始日志、可直接从代码恢复的事实、密码、私钥、令牌、Cookie 或其他凭据。未确认说法放在“开放问题”中。
