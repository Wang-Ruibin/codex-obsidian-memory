Run the weekly project kickoff brief for the configured Obsidian memory vault.

Read the memory home, global memory, project index, and every project and branch page. Treat a project as active only when notes contain an explicit unfinished goal, blocker, next step, or recent durable progress. Do not treat placeholder text as progress.

Create or replace the configured weekly brief with:

1. ISO week and generated time.
2. The five highest-value evidence-backed tasks, with project links, expected outcomes, and priority rationale.
3. Current blockers, affected work, and concrete unblock actions.
4. Historical notes needed this week, linked to exact decisions, branch pages, or failure lessons.

If fewer than five real tasks are documented, do not invent work. Label the missing slots as priority awaiting confirmation and state what information is missing. Replace the prior brief instead of appending a weekly transcript. Never store credentials.

为已配置的 Obsidian 长期记忆知识库运行每周项目开工简报。

读取记忆首页、全局记忆、项目总览以及每个项目主页和分支页。只有笔记中存在明确未完成目标、阻塞、下一步或近期持久进度时，才把项目视为活跃；不得把占位文字当作进度。

创建或替换已配置的每周简报，包含：

1. ISO 周和生成时间。
2. 五项有证据支持、价值最高的任务，包含项目链接、预期结果和优先理由。
3. 当前阻塞、受影响工作和具体解除动作。
4. 本周所需历史资料，并链接到精确决策、分支页或失败经验。

如果记录中的真实任务不足五项，不得虚构工作；把缺少位置标记为“优先级待确认”，并说明缺少什么信息。替换上期简报，不追加每周流水账。永远不得保存凭据。
