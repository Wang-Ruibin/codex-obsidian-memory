为已配置的 Obsidian 长期记忆知识库运行每月健康体检。

遵守知识库的 AGENTS.md，使用下方提供的已解析配置路径，包括自定义布局。覆盖知识、项目、共享经验和普通对话四个独立分区。在非隐藏 Markdown 笔记中检查重复事实、过期说法、冲突、断链、孤立节点、重复项目主页、重复分支身份和项目总览漂移。只解决有清晰证据支持的问题；不确定冲突标记为待审阅。

GitHub 项目按精确 github_repo、本地项目按已登记 project_id、分支按区分大小写的 working_branch 核对。遵守排除项和本地登记停用状态；不得从名字、正文或默认分支推断本地身份与当前进度。对话检查只限结构性 frontmatter、conversation_id 唯一性、索引归属和链接。不得读取或总结对话正文、访问聊天数据库或会话记录、开启记忆，或改变标题同步与授权设置。

同时检查共享经验索引中的重复主题、缺失链接、过时适用条件和来源／分支不匹配。核对来源仓库是否已被排除、验证日期是否仍能支撑相关说法。提出重新验证或停用建议；不得虚构验证结果，也不得只因运行了本次体检就刷新验证日期。

在已配置报告内，只更新 `updated` frontmatter 日期和“最新体检”部分，包含月份、范围、有证据支持的修复、未解决冲突、建议归档项和图谱统计。其他笔记的修复必须属于本次体检范围且有明确证据；只有本次形成持久维护结论时才更新维护页。替换上期体检，不追加流水账。

使用下方提供的当前知识库校验器及体检前结果，不使用旧 .automation/validate_graph.py。结束前重新验证项目主页数、分支页数、精确身份、本地登记、共享经验来源、对话结构、断链和孤立节点。runner 会在记录周期完成前再次验证。

永远不得自动删除、移动或归档文件；归档建议只是一种标记。不要仅为美化图谱而新增页面。使用已配置语言提供可见、逐文件的知识库回写审查，并遵守知识库的结束规则。永远不得保存凭据。
