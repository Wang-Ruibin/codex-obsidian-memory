# 长期记忆协议 — 纯 Skill 版

本知识库是本地持久记忆来源，不是聊天流水。使用独立的 `codex-obsidian-memory-skill`，没有生命周期 Hook 或后台进程。

## 任务开始

运行 Skill 的 `skillctl start --cwd <workspace>`，立即使用上下文并保留任务 ID。压缩或中断后用相同任务 ID 恢复未结束工作。使用精确 GitHub origin 身份或明确登记的本地项目 ID，只加载当前分支页和直接链接的非分支子页。未登记普通对话默认关闭，用户明确开启实际会话 ID 后才生效。

## 任务进行

实质实现前、失败后或改变策略前检索共享经验；候选不适用时重试项目。按段读取证据，核对条件和来源，历史分支只作参考。编辑共享或全局笔记前，以当前任务 ID 通过 `claim-shared` 逐个占用；其他任务占用则延后。同一项目文件的编辑另行协调。

## 任务结束

保留持久目标、约束、背景、决定、已验证结果、可迁移失败和下一步。分支进度写精确分支页，仓库级稳定背景写主页。共享方法保留适用条件、限制、来源身份、分支、笔记和验证日期。不得把聊天流水、凭据、原始日志或猜测写成事实。

运行 `changes` 和 `validate`，在可见的“知识库回写审查”中逐个列出文件及具体变化，邀请纠正。将 UTF-8 审查草稿交给 `finish`；没有 Markdown 变化时省略审查部分和文件参数。命令校验覆盖并只释放本任务占用，没有宿主 Stop 强制检查或隐藏标记要求，随后删除临时草稿。

## 普通对话

明确授权后，以实际会话 ID 执行 `conversation-enable/disable`，已有本地与 GitHub 项目路由优先，只加载对应对话笔记。文件名在 `start` 或显式 `conversation-sync` 时同步，关闭内容记忆后仍同步，除非明确冻结标题。Skill 空闲时不执行任何后台工作。不得删除或移动知识库。
