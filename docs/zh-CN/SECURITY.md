# 安全策略

[English](../../SECURITY.md)

## 报告安全漏洞

请使用 [GitHub 私密漏洞报告](https://github.com/Wang-Ruibin/codex-obsidian-memory/security/advisories/new)。项目处于早期开发阶段时，安全修复应用于 `main` 上的最新版本。

报告、Issue、Pull Request、测试夹具和日志中不得包含真实令牌、私钥、Cookie、私人知识库页面或其他凭据。

## 信任边界

- 本插件运行本地生命周期 Hook，并读取用户选择的 Markdown 知识库。信任前请在 `/hooks` 中审阅 Hook 定义。
- 仓库身份来自只读 Git 命令。每个笔记都解析在配置的知识库内部，注入前遮蔽常见秘密模式。没有任何命令会删除或移动知识库。
- 提示开始时，插件只保存相对 Markdown 路径与 SHA-256 哈希的临时映射，不复制笔记正文。Stop 阶段比较哈希，并要求最终回复包含可见回写审查标题、披露标记和审查标记。Codex 会被要求说明每个修改文件，但 `0.4.0` 无法判断说明是否完整、准确；依赖新记忆前请亲自审阅。成功结束后删除本轮快照。
- 分支页保留完整 `working_branch` 值，但 `0.4.0` 使用不区分大小写的比较。在该限制移除前，请避免只在字母大小写上不同的分支名。
- Hook 上下文阈值为 16,000 token；过大的上下文可能只向 Codex 提供头尾预览，完整输出另行保存。
- 秘密遮蔽只是纵深防御，不是完整秘密扫描器。请勿在 Markdown 记忆文件中保存凭据。
